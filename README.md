# Asset Browser

Browse, view, and download the Minecraft vanilla assets from your browser. A web version of the [Asset Browser Blockbench plugin](https://ewanhowell.com/plugins/asset-browser/).

Supports Java releases, snapshots, old beta/alpha, and Bedrock releases/previews (via [bedrock-samples](https://github.com/Mojang/bedrock-samples)).

## Features

- Browse any version's assets like a folder directory, with grid and list views, search, sorting, keyboard navigation, and a pinnable sidebar
- Inline previews: textures, animated textures (mcmeta and Bedrock flipbooks), and rendered block/item models, blockstates, and item definitions via [block-model-renderer](https://github.com/ewanhowell5195/block-model-renderer)
- File viewer for images, JSON/text files, and sounds
- Download single files, or folders/selections as a zip
- Optional objects (sounds, languages, panorama, etc.) from the version's asset index
- Version jars are cached in IndexedDB so they only download once
